# ESP32-S3 LED Bar Graph Controller

An LED running-light controller with a trailing-light effect, developed using the ESP32-S3 and ESP-IDF.

The application controls eight LEDs independently using PWM and allows the animation to be started and stopped with a push button.

## Features

- Independent brightness control of eight LEDs using PWM
- Trailing-light effect generated by varying PWM duty cycles
- Start/stop control via a push button
- All LEDs turn off when the animation is stopped
- Button debouncing to prevent unintended multiple inputs
- FreeRTOS task separation and queue-based inter-task communication

## Tech Stack

- **Language:** C
- **Framework:** ESP-IDF v6.1
- **Target MCU:** ESP32-S3
- **RTOS:** FreeRTOS
- **PWM Driver:** ESP-IDF LEDC driver

## Hardware

- **Development Board:** ESP32-S3 development board
- **LED outputs:** GPIO 42, 41, 40, 39, 38, 47, 21, 20
- **Button input:** GPIO 13

The GPIO assignments correspond to the external LEDs and button used in the development setup.

## Implementation Details

| Parameter | Value |
|---|---|
| PWM frequency | 5 kHz |
| PWM resolution | 8 bits |
| Button polling interval | 10 ms |
| Button debounce interval | 30 ms |
| LED animation update interval | 100 ms |

## Software Architecture

The application uses two FreeRTOS tasks to separate button input handling from LED control.

### Button Task

- Polls the button input every 10 ms
- Applies a 30 ms debounce interval
- Sends a toggle event to the LED task through a FreeRTOS queue

### LED Task

- Receives button events from the queue
- Manages the animation state
- Updates LED PWM duty cycles every 100 ms while the animation is running
- Turns off all LEDs when the animation is stopped

### Inter-task Communication

A FreeRTOS queue transfers button events from the button task to the LED task.

The LED task exclusively manages the animation state and PWM updates. This design separates input handling from LED control and avoids concurrent modification of the animation state by multiple tasks.

## Build

Open an ESP-IDF terminal in the project directory and run:

```powershell
idf.py build
```

## Flash and Monitor

Connect the development board and run:

```powershell
idf.py -p COM3 flash monitor
```

Replace `COM3` with the serial port assigned to your development board.

To exit the serial monitor, press `Ctrl+]`.

## Key Learning Points

- Creating and scheduling FreeRTOS tasks
- Queue-based inter-task communication
- Button debouncing and input handling
- PWM generation using the ESP-IDF LEDC driver
- Periodic processing and state management
- Separating input handling from hardware control
